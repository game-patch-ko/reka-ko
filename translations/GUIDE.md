# REKA 한국어 번역 지침

## 작품
REKA는 19세기 말 동유럽을 배경으로, 슬라브 민담을 소재로 한 마녀 수련·오두막 건축 게임이다.
젊은 마녀 레카(Reka)가 전설적인 마녀 바바 야가(Baba Jaga)의 제자가 되어, 닭다리가 달린 오두막을 짓고 시련을 치르며
마을 사람과 동물, 정령, 유령의 문제를 해결한다. 공업화로 옛 믿음이 사라져 가는 시대의 쓸쓸함과 소박한 유머가 공존한다.
번역은 민담을 듣는 듯한 자연스럽고 따뜻한 한국어를 목표로 한다. 번역투를 피하고, 직역보다 의미와 말맛을 살린다.

## 말투
키 경로와 ctx의 설명·감정으로 화자를 판단한다. `_Prompt`는 플레이어(레카)가 고르는 대사, `_Rumor`, `Response`는 대개 상대의 답이다.

| 화자 | 말투 |
|---|---|
| 바바 야가 → 레카 | 노련하고 짓궂은 노파의 반말. `~구나`, `~느냐`, `~거라`, `~지` |
| 레카 → 바바 야가 | 공손하지만 친근한 해요체 |
| 레카 → 마을 사람·동물·정령 | 해요체. 아이나 동물에게는 다정한 해요체 |
| 레카의 독백·일지·할 일 메모 | `~해야겠어`, `~인가 봐` 같은 혼잣말 반말 |
| 마을 사람 → 레카 | 해요체. 노인은 `~라우`, `~다네`처럼 인물에 맞게. 거친 인물은 반말 가능 |
| 말하는 동물, 루트키, 레시 | 개성을 살리되 인물 안에서는 일관되게 |
| 내레이션, 도입부, 아이템·가구 설명 | `~다` 평서체 |
| 메뉴, 버튼, 알림 | 간결한 명사형. `저장`, `계속하기` |
| 설정·도움말 설명, 튜토리얼 안내문 | `~합니다` 체. 문장 끝에 마침표 |

호칭: 레카를 부르는 말은 `레카`, `강 고양이야`, `마녀님`처럼 문맥에 맞게 한다. `당신`, `그녀`, `그`는 되도록 쓰지 않고 이름이나 생략으로 처리한다.

## 형식 규칙 (반드시 지킴)
- `{0}`, `{1}`, `{action:Place}`, `{sawAction}` 같은 변수는 글자 그대로 모두 유지한다. 위치는 한국어 어순에 맞게 옮겨도 된다.
- `<i>`, `</i>`, `<U>` 같은 태그도 그대로 유지한다.
- 줄바꿈 `\n`의 개수를 원문과 같게 유지한다. 대사에서 `\n`은 대사 말풍선 하나를 뜻한다. 줄을 합치거나 나누지 않는다.
- 원문의 앞뒤 공백을 유지한다. 예: ` of these body parts...`처럼 앞에 공백이 있으면 번역에도 둔다.
- 변수 뒤 조사는 받침을 알 수 없으므로 `을(를)`, `이(가)`처럼 쓰지 말고 조사가 필요 없는 문장으로 바꾼다. 예: `{0}: 정말 보관할까요?`
- 한자, 영어를 남기지 않는다. 단 `Steam`, `Discord`, `DLSS`, `FSR`, `V-Sync`, `HDR`, 숫자와 단위는 그대로 둔다.
- 말줄임표는 원문대로 `...` 또는 `…`를 쓴다. 따옴표는 원문을 따른다.
- 버튼, 이름, 탭 항목은 원문처럼 짧게 쓴다. 번호(`Hanging Herb 13`)는 유지한다.
- 대문자 강조(`AND`)는 문맥에 맞게 살리거나 작은따옴표를 쓰지 않고 자연스럽게 표현한다.
- 끊어서 조립되는 문장 조각(`Reveal a` + `zone!`)은 이어 붙여도 자연스러운 조각으로 만든다.

## 자주 틀리는 점
- 레카의 일지, 도감 메모, `Log`, 할 일은 끝까지 혼잣말 반말로 통일한다. `~했어`, `~해야겠어`, `~인가 봐`. 한 항목 안에서 `~다`와 섞지 않는다.
- 민담을 들려주는 긴 설명, 아이템과 가구 설명은 끝까지 `~다` 평서체로 쓴다.
- 레카가 바바 야가를 부르는 `mistress`는 `스승님`이다.
- 원문의 `(Flower Name)`처럼 괄호로 된 개발용 자리표시자는 그대로 둔다.
- `\r\n`이 있으면 그대로 유지한다.
- 같은 원문은 같은 번역으로 옮긴다. 같은 파일 안의 반복 항목(`Cabbage Plant`, `Garlic Plant`)은 같은 틀을 쓴다.
- `I witch you...`처럼 말장난은 뜻을 살린 자연스러운 표현으로 옮긴다.
- 개발 용어를 직역하지 않는다. `game assets`는 `게임 데이터`처럼 플레이어가 쓰는 말로 옮긴다.

## 용어
`glossary.json`을 따른다. 없는 고유명사는 원어 발음을 한글로 옮기고, 민담 속 용어는 뜻이 통하게 옮긴다.
흔한 낱말이 고유명사처럼 대문자일 때(`Trial`, `Shrine`)도 용어집대로 쓴다.
